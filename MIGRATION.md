# Migration guide


The migration guide is a work in progress.


## Removed classes
- `.-dark-theme`: Set `html { color-sheme: dark; }` instead.
- `.-no-light-theme`: Set `html { color-sheme: light; }` instead.

## Renamed classes
- `.f-row` -> `.flex-row`
- `.f-col` -> `.flex-col`
- `.f-switch` -> `.flex-switch`

## Rename variables
- `--f-switch-threshold` -> `--flex-switch-threshold`
